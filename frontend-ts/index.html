Documentation: "bootstrapping" zero-rates

Notation:
  • $\tau$ is the year fraction; for simplicity we ignore day-count conventions here.
  • $C_{\tau}$ is the (annual) coupon rate for a $\tau$-year bond: that is, a bond with face value $A$, coupon rate $R$, and semiannual coupon payments, pays $\frac{1}{2}AC$ every 6 months.
  • $P_{\tau}$ is the present value factor (or discount factor) for maturity $\tau$: it is the cash price to receive $1 $\tau$ years from now.

Given the par yields $C_{\tau_{1}}, C_{\tau_{2}}, \ldots C_{\tau_{N}}$ for Treasury securities maturing at times $\tau_{1}, \ldots, \tau_{N}$, our goals are:

  1. Select an appropriate interpolation method to infer/compute values $C_{\tau}$ for all $\tau_{1} \leq \tau \leq \tau_{N}$;
  2. Use the "curve" of values $C_{\tau}$ ($\tau_{1} \leq \tau \leq \tau_{N}$) to iteratively compute the "zero-coupon" discount factors
    \[ P_{\tau_{1}}, P_{\tau_{2}}, \ldots, P_{\tau_{N}}. \]
  3. Use the values $(P_{\tau_{1}}, \ldots, P_{\tau_{N}})$ to interpolate a "curve" of values $P_{\tau}$ for $\tau_{1} \leq \tau \leq \tau_{N}$.
  4. Map the values $P_{\tau}$ to "zero/spot rates" $Z_{\tau}$ under a predetermined discounting scheme.

Interpolation Methods

Given "known" points $(t_0, x_0)$ and $(t_1, x_1)$, we want to determine values $x_{t}$ for all $t_0 \leq t \leq t_{1}$. It is standard to normalize

\[ t_0\leq t \leq t_1 \quad\text{via setting}\quad \lambda := \frac{t - t_0}{t_1 - t_0}, \quad \text{so that}\quad 0 \leq \lambda \leq 1. \]
Note: This definition of $\lambda$ is commonly expressed via
\[ t = (1–\lambda)t_{0} + \lambda t_{1}, \qquad (0 \leq \lambda \leq 1) \]
Linear interpolation
\[ x_{t} := (1-\lambda)x_0 + \lambda x_1 \qquad\Leftrightarrow\qquad x_{t} := \Big(\frac{t_{1}-t}{t_{1}-t_{0}}\big) x_{0} + \Big(\frac{t-t_{0}}{t_{1}-t_{0}}\Big) x_{1}. \]

This is the same as the intuitive "slope form"

\[ x_{t} := x_{0} + \frac{x_1-x_0}{1-0} \lambda \qquad\Leftrightarrow\qquad x_{t} := x_{0} + \Big(\frac{x_1-x_0}{t_1-t_0}\Big)(t-t_0), \]
Log interpolation
\[ x_{t} := x_{0}^{1-\lambda}x_{1}^{\lambda} \quad\Leftrightarrow\quad x_{0}^{(\frac{t_1-t}{t_1-t_0})}x_{1}^{(\frac{t-t_0}{t_1-t_0})} \quad\Leftrightarrow\quad x_{t} := \exp\!\big[ (1-\lambda)\log x_{0} + \lambda\log x_{1} \big] \]

The bootstrapping

For T-Bills ($\tau \leq \frac{1}{2}$)

Treasury bills have $\tau \leq \frac{1}{2}$ and have no coupon payments; for these, the Treasury publishes the "Bond-Equivalent Rates", which correspond to zero-coupon prices directly via

\[ P_{\tau} = (1 + C_{\tau}\,\tau)^{-1}. \]
For T-Notes and T-Bonds ($\tau \geq 1$)

Treasury Notes and Bonds have semiannual coupon payments, which we assume are reinvested. To simplify our notation, we reset our "unit" of time so that

\[ 6\text{ months} = 1 \text{ ``period''}. \]

For instance then, a bond maturing in 18 months has cash flows at times $t=1, 2, 3$.

The price of a 12-month (2 periods) bond having Par Value \$1 and annual coupon rate $C_{2}$ satisfies

\[ \tfrac{1}{2}C_{2}P_{1} + (1+\tfrac{1}{2}C_{2})P_{2} = 1; \]

the price of an 18-month bond having annual coupon rate $C_{3}$ satisfies

\[ \tfrac{1}{2}C_{3}P_{1} + \tfrac{1}{2}C_{3}P_{2} + (1+\tfrac{1}{2}C_{3})P_{3} = 1, \]

and so forth for 24-, 30-, 36-, ... month maturity bonds. Having determined $P_{1} = (1+\tfrac{1}{2}C_{1})^{-1}$, the above equations allow us to iteratively solve for $P_{k}$ for all $k \geq 2$ for which $C_{k}$ is defined; in particular, we have

\[ P_{k} = \frac{1 - \tfrac{1}{2}C_{k}(P_{1}+\cdots+P_{k-1})}{1 + \tfrac{1}{2}C_{k}} \qquad (k \geq 2). \]

Converting prices to zero-rates

Given the curve of values $P_\tau$, there are several ways to convert this into zero-rates $z_\tau$; here we consider $\tau$ fixed and simply write $z=z_\tau$ to highlight the different dependencies of $P_\tau$ on the "annual rates" $z$.

Convention Equation for $P_\tau = P_{\tau}(z)$
Annual compounding $P_{\tau}(z) = (1+z)^{-\tau}$
Compounding $m$-times per annum $P_{\tau}(z) = (1+z^{(m)}/m)^{-m\tau}$
Continuous compounding $P_{\tau}(z) = e^{-z\tau}$
