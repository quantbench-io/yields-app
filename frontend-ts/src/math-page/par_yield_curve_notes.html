Given the par yields $R_{\tau_{1}}, R_{\tau_{2}}, \ldots R_{\tau_{N}}$ for Treasury securities, our goals are:

  1. Select an appropriate interpolation method to infer/compute values $R_{\tau}$ for all $\tau_{1} ≤ \tau ≤ \tau_{N}$;
  2. Use the curve $R_{\tau}$ (with $\tau_{1} ≤ \tau ≤ \tau_{N}$) to iteratively compute the "zero-coupon" discount factors (or "price factors")
    \[ P_{\tau_{1}}, P_{\tau_{2}}, \ldots, P_{\tau_{N}}; \]
    in particular, $P_{\tau}$ is the cash price of receiving \$1 $\tau$ years in the future.
  3. Interpolate (using some selected method) the values $(P_{\tau_{1}}, \ldots, P_{\tau_{N}})$ to produce a "curve" $P_{\tau}$ for $\tau_{1} ≤ \tau ≤ \tau_{N}$.
  4. Map the values $P_{\tau}$ to "zero/spot rates" $Z_{\tau}$ under a predetermined discounting scheme.
For T-Bills ($\tau ≤ \tfrac{1}{2}$)

Treasury bills have $\tau ≤ \tfrac{1}{2}$ and have no coupon payments; for these, the Treasury publishes the "Bond-Equivalent Rates", which correspond to zero-coupon prices directly via

\[ P_{\tau} = (1 + R_{\tau}\tau)^{-1}. \]
For T-Notes and T-Bonds ($\tau ≥ 1$)

To handle Treasury Notes and Bonds, which have $\tau ≥ 1$ and have semiannual coupon payments (which we assume are reinvested), to simplify our notation we change our unit of time to be

\[ 1\text{ period} := 6\text{ months}, \]

so that a bond maturing in 18 months has cash flows at times $t=1, 2, 3$.

The price of a 12-month (2 periods) bond having Par Value \$1 and annual coupon rate $R_{2}$ satisfies

\[ \tfrac{1}{2}R_{2}P_{1} + (1+\tfrac{1}{2}R_{2})P_{2} = 1; \]

the price of an 18-month bond having annual coupon rate $R_{3}$ satisfies

\[ \tfrac{1}{2}R_{3}P_{1} + \tfrac{1}{2}R_{3}P_{2} + (1+\tfrac{1}{2}R_{3})P_{3} = 1, \]

and so forth for 24-, 30-, 36-, ... month maturity bonds. Having determined $P_{1} = (1+\tfrac{1}{2}R_{1})^{-1}$, the above equations allow us to iteratively solve for $P_{k}$ for all $k ≥ 2$ for which $R_{k}$ is defined; in particular, we have

\[ P_{k} = \frac{1 - \tfrac{1}{2}R_{k}(P_{1}+\cdots+P_{k-1})}{1 + \tfrac{1}{2}R_{k}} \qquad (k ≥ 2). \]

Interpolation methods

Given "known" points $(t_0, x_0)$ and $(t_1, x_1)$, we want to determine values $x_{t}$ for all $t_0 ≤ t ≤ t_{1}$. It is standard to normalize

\[ t_0 ≤ t ≤ t_1 \qquad\text{via setting}\qquad \lambda := \frac{t - t_0}{t_1 - t_0}, \quad 0 ≤ \lambda ≤ 1. \]

Note: This definition of $\lambda$ is commonly expressed via

\[ t = (1-\lambda)t_{0} + \lambda t_{1}, \qquad (0 ≤ \lambda ≤ 1) \]
Linear interpolation:
\[ x_{t} := (1-\lambda)x_0 + \lambda x_1 \qquad\Leftrightarrow\qquad x_{t} := \Big(\frac{t_{1}-t}{t_{1}-t_{0}}\Big) x_{0} + \Big(\frac{t-t_{0}}{t_{1}-t_{0}}\Big) x_{1}. \]

This is the same as the intuitive "slope form"

\[ x_{t} := x_{0} + \frac{x_1-x_0}{1-0}\lambda \qquad\Leftrightarrow\qquad x_{t} := x_{0} + \Big(\frac{x_1-x_0}{t_1-t_0}\Big)(t-t_0), \]
Log interpolation:
\[ x_{t} := x_{0}^{1-\lambda}x_{1}^{\lambda} \quad\Leftrightarrow\quad x_{0}^{(\frac{t_1-t}{t_1-t_0})}x_{1}^{(\frac{t-t_0}{t_1-t_0})} \quad\Leftrightarrow\quad x_{t} := \exp\!\Big[ (1-\lambda)\log x_{0} + \lambda\log x_{1} \Big] \]
