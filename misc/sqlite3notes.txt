Creating a database
    sqlite3 db01
  - this will open the sqlite3 console ( `sqlite> `) when running;
  - creates db01 if it doesn't exist already.

Importing a table from CSV
    sqlite> .mode csv 	-- ensures files read as CSV
    sqlite> .import data.csv mytable
  - this will auto initialize each column as type TEXT
  - it will automatically create `mytable` and save it to `db01`

Specifying column types for table import
========================================
The "usual/crude" way to initialize a table is via something like

sqlite> CREATE TABLE tbl2 (
...>  	  f1 varchar(30) primary key,
...>	  f2 text,
...>	  f3 real
...>	);

If you have many columns to initialize, you can automate this using an in-terminal python script to print out a list of columns+types like so:

**Using my example from working with `pars-2024-11.csv`**

(when hitting ENTER after the `"` you will see something like `dquote>`, which will let you type new lines until you enter another `"`. Careful though! If your python script includes `"` for strings, that will tell `dquote>` your input is complete, causing errors)

% python3 -c "
import csv
headers = next(csv.reader(open('pars-2024-11.csv'))) # note quotes ' '
cols = ", ".join( f'\"{header}\" REAL' if header != 'date' else '\"date\" TEXT' for header in headers )
print( f'CREATE TABLE mytable ({cols});' ) 
"

This prints that last line/string to console, which you can then pipe into sqlite3:
% python3 -c "..." | sqlite3 db01

Then you can return to sqlite console:
% sqlite3 db01
sqlite> .mode csv
sqlite> .import --skip 1 pars-2024-11.csv mytable

(`--skip 1` because you already have the headers set from the previous step)

or a one-liner:
% sqlite3 db01 -cmd ".mode csv" ".import --skip 1 data.csv mytable"
